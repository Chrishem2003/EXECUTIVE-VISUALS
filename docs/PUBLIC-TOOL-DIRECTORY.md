## Product interpretation

- Platform B's public catalogue is outcome-oriented: scripts, URLs, PDFs, slides, audio, podcasts, training, avatars, captions, repurposing, presentations and channel-specific deliverables.
- Platform C's workspace is operation-oriented: select an enhancement/edit task, upload or import media, configure a focused operation or sequence, then preview/export.
- Executive Visuals should combine both patterns: outcome-first project planning plus a composable, inspectable processing pipeline.
- Keep provider catalogues versioned and refreshable. Do not hard-code third-party tool lists, plan entitlements or costs as permanent truths.
